# Hip Afro Travel

Statisk Next.js-sida för Hip Afro Travels gruppresa till Gambia.

## Getting Started

Installera beroenden och kör utvecklingsservern:

```bash
npm ci
npm run dev
```

Öppna [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Scripts

- `npm run dev` startar lokal utveckling.
- `npm run lint` kör ESLint.
- `npm run build` bygger statisk export till `out/`.

## Deploy

Projektet använder `output: "export"` och GitHub Pages-prefix i produktionsbyggen som körs via GitHub Actions.
